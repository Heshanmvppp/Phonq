# Phonq Roadmap

The public roadmap is also rendered on the site at [phonq.vercel.app/product/roadmap](/product/roadmap).

## v1.0 — Shipped

- Global search across the Jamendo catalog
- Favorites & playlists, synced with Google OAuth
- Listening history
- Global player: queue, shuffle, repeat, live waveform

## v1.1 — In progress

- [x] Artist pages (discography, bio, similar artists)
- [x] Album pages & discography
- [ ] Download buttons with license display

## v1.2 — Planned

- [x] Queue drag-and-drop reordering
- [x] Personalized recommendations from your history
- [ ] i18n (translations)
- [x] Automated tests (Vitest for API routes + player state)

## v1.3 — Under consideration

- [ ] Listening statistics ("wrapped"-style summaries)
- [ ] PWA with offline queue

## v2.0 — Under consideration

- [ ] Native mobile apps
